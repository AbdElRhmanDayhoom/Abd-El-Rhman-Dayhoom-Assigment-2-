📊 Data Analytics Lifecycle & Key Components

Phase / Type Description Common Tools & Technologies
1. Data Collection Gathering raw data from various sources like databases, APIs, web scraping, or surveys. SQL, Python (BeautifulSoup), APIs, Google Analytics
2. Data Cleaning Removing duplicates, handling missing values, and correcting errors to ensure data quality. Python (Pandas), R, OpenRefine
3. Descriptive Analytics Examining historical data to understand what has happened in the past. Excel, SQL, Tableau, Power BI
4. Diagnostic Analytics Investigating data to discover the root causes of past events or trends ("Why did it happen?"). SQL, Python, Data Mining tools
5. Predictive Analytics Using statistical models and machine learning to forecast future outcomes ("What is likely to happen?"). Python (Scikit-learn), R, SAS
6. Prescriptive Analytics Recommending actions to take advantage of predictions or solve problems ("What should we do?"). Optimization algorithms, Python, Decision Trees
7. Data Visualization Presenting findings through charts, graphs, and dashboards for stakeholders. Tableau, Power BI, Matplotlib, Seaborn
